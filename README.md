# Consentext Phase 3.75 Working Prototype

Open `index.html` in a browser.

This active prototype is based on the expanded `Phase 3.75 3-16` document set.
`consentext_architecture_onepager_03.16.2026.docx` remains the precedence source when documents overlap.

What the prototype now includes:
- A governed request preview above the fold
- A workflow spine from data selection to audit proof
- A lane matrix showing privacy, capability, and control tradeoffs
- A tabbed workspace for Vault, Consent, Gateway, and Audit review
- A source-versus-governed-output contrast inside the Gateway Lab
- Policy chips, richer state changes, and audit filtering
- Off-Board contrast behavior in the gateway simulator
- A health-dashboard surface with vitals cards, trust timeline, and pod readiness table

Recommended review path:
1. Start with the hero preview and workflow ribbon.
2. Use the tabbed workspace to move from Vault to Consent to Gateway.
3. Apply a policy, run routing, and inspect the source versus governed output.
4. Trigger an API fetch test.
5. Filter the audit feed by allow, deny, policy, or off-board events.
